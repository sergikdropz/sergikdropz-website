# ⚠️ Instagram Basic Display API - Deprecated

## Important Update

**Instagram Basic Display API was discontinued on December 4, 2024.**

This is why you cannot find it in the Facebook Developer Console - it's no longer available!

## ✅ Solution: Manual Posts (Recommended)

Since the API is deprecated, **manual posts are the best solution** for personal Instagram accounts.

### Why Manual Posts Work Best Now:

1. ✅ **No API needed** - Works immediately
2. ✅ **No deprecation issues** - Not affected by API changes
3. ✅ **Full control** - Choose exactly which posts to display
4. ✅ **Always works** - No tokens to expire or break
5. ✅ **Easy updates** - Just add new URLs when you want

## 🚀 How to Use Manual Posts

### Step 1: Get Post URLs

**On Mobile:**
1. Open Instagram app
2. Go to a post
3. Tap three dots (⋯) → "Copy link"

**On Desktop:**
1. Go to instagram.com
2. Click a post
3. Copy URL from address bar

### Step 2: Add to Your Site

1. **Start dev server:**
   ```bash
   cd web
   npm run dev
   ```

2. **Visit:**
   ```
   http://localhost:3000/instagram-helper
   ```

3. **Paste post URLs** and click "Save"

4. **Done!** Posts appear on homepage immediately! ✅

## 🔄 Alternative: Instagram Graph API

If you have an **Instagram Business or Creator account**, you could use Instagram Graph API instead:

- Requires Business/Creator account (not personal)
- More complex setup
- Different API endpoints
- Still requires Facebook Developer Console setup

**For personal accounts, manual posts are the only option now.**
