# 🚀 Instagram Quick Start

## 2-Minute Setup

### Step 1: Add Redirect URI
1. Go to: https://developers.facebook.com/apps/1186575606889765
2. **Instagram Basic Display** → **Basic Display**
3. Add: `http://localhost:3000/api/instagram/callback`
4. Save

### Step 2: Connect
1. `cd web && npm run dev`
2. Visit: `http://localhost:3000/instagram-helper`
3. Click **"🔗 Connect Instagram Account"**
4. Authorize
5. Done! ✅

## That's It!

Posts will now:
- ✅ Display on homepage
- ✅ Auto-refresh every 6 hours
- ✅ Update automatically
