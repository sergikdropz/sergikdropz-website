## TIPS FOR RECORDING VOICE-OVER

1. Record in a quiet room — even a closet with clothes absorbs echo.
2. Speak 10–15% slower than feels natural. Viewers need time to read the screen.
3. Each [PAUSE] marker = don't speak. Let the UI breathe.
4. Leave 1 second of silence at start and end for editing headroom.
5. Use QuickTime → New Audio Recording with the built-in mic, or AirPods mic.
6. Sync in iMovie: Add video track → Add audio track → align by waveform peaks.
